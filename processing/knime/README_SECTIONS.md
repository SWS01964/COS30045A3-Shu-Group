# Adding a chapter section to the KNIME workflow

The workflow `knime/BeyondTheRoadToll/` is generated by `build_workflow.py` from small Python files. One file per chapter,
one metanode per chapter. Keep it hand-sized: only the nodes listed for your section in `CLAUDE_CONTEXT/REBUILD_PLAN.md` 3.x,
short labels ("Traffic only", "Sum by year"), tidy grid, a coloured note per area.

## 1. Write `processing/knime/sections/chN.py`
Copy `sections/ch1.py` (the worked example). A section module has three things:

```python
from knimelib import *
NAME = "Ch2 Getting older"   # metanode title on the canvas
IN = (0, 1)                  # which shared tables it needs, in order (see below)
def build():                 # returns the metanode's inside as a knimelib.Workflow(NAME, n_in=len(IN))
    w = Workflow(NAME, n_in=len(IN))
    base, pop = w.inport(0), w.inport(1)          # metanode in-port k = shared table IN[k]
    ...nodes via w.node(type, label, (col, row), [inputs], model)...
    w.node("CSV Writer", "ch2_age_roaduser.csv", (col, row), [last], out_file="ch2_age_roaduser.csv")
    w.note("Ch2 ...", "one-line description", (c0, r0, c1, r1), "blue")   # coloured annotation inside the metanode
    return w
```

### In-port convention (shared tables)
| number | table | columns |
|---|---|---|
| 0 | clean base (end of the top-level clean-up chain) | `year, month, remoteness, age_group, sex, road_user, counterparty, cases, bed_days, died, died_bed_days, hosp, bed_days_surv` (plus the constant column `Cause of injury` = Traffic; ignore it) |
| 1 | population | `year, age_group, population` (age bands `0-7 ... 75+` and `All ages`, ABS ERP at 30 June, 2011-2021) |
| 2 | road deaths | `year, road_deaths` (ARDD, 2011-2021) |

`IN` lists the numbers a section wants, in the order of its metanode in-ports: `IN = (0,)` for base only, `IN = (0, 1)` for base
+ population. A section that reads its own file (Ch4 state check, Ch5) needs only `IN = (0,)` or `IN = ()`.
Metanodes may have no output ports; the sink is the CSV Writer inside.

### Files
- Readers: `excel_reader(knimelib.STATE_XLSX, sheet=..., c0=..., header_row=...)` or `csv_reader(name)` with `text=` in `w.node`.
  Names (`NATIONAL_XLSX`, `STATE_XLSX`, `FIRST_NATIONS_XLSX`, `ERP_CSV`, `ARDD_CSV`) are read from the workflow's own `data/` folder.
- Writers: `w.node("CSV Writer", label, at, [src], out_file="<name>.csv")`; the name must equal the reference file in `data/reference/`.
  Output goes to `knime/BeyondTheRoadToll/data/`.

### Grid
`at=(column, row)`, one cell = 150 px. Flow left to right, one process per row (see ch1: main chain row 0, side input row 1).
Annotation boxes `(c0, r0, c1, r1)` are in grid cells and are drawn with margins around them.

## 2. Register it
`build_workflow.py` has `SECTIONS = ["ch1", "ch2", "ch3", "ch4", "ch5"]`. A listed module that does not exist yet is skipped
("skipping ch2: not written yet"); once your file exists it is built automatically. Chapters sit in column 7 of the top-level
grid, one row each, in list order, with a green note "3 Chapter sections".

## 3. Build, run, compare
Section agents work in parallel, so **build into your own folder** (never the default one) and build only your section:
```
S=/private/tmp/claude-501/-Users-tritran2411-Desktop-COS30045A3-Shu-Group/f120d774-ff5a-4cd8-bf80-3d957513403b/scratchpad
python3 processing/knime/build_workflow.py --out $S/build_ch2 --only ch2          # clean-up + supplementary + ch2 only
python3 processing/knime/run_headless.py $S/build_ch2                             # exit 0 only if every node executed
PY=<venv>/bin/python                                                              # any python with pandas
$PY -I processing/knime/compare.py --dir $S/build_ch2/data --files ch2_age_roaduser.csv
```
`--only ch2,ch3` builds several sections; `--knwf` also zips the workflow next to the folder. Runs in different folders can run at
the same time (each uses its own temp KNIME workspace and kills only its own process group).
The orchestrator does the full build into `knime/BeyondTheRoadToll` and runs `compare.py --copy` (copies to `data/processed/`,
only when `--dir` is the default). `compare.py` prints PASS/FAIL per file with the first differing cells, and skips reference files
with no KNIME output yet.

## Gotchas
- **KNIME never exits after a headless run** (a Chromium helper keeps it alive). `run_headless.py` starts it in its own process
  group, waits for the log line "Workflow execution done", then kills the group. Failure = the log line "Workflow did not execute
  sucessfully" (sic). A run takes about 10 s; if a run hangs, check `ps aux | grep "KNIME 5.5"`.
- **Math Formula has no `min()`/`max()`** (error "Unrecognized symbol min"). Use nested `if(cond, a, b)`. These work: `if`, `round`, `^`,
  `+ - * /`, `<= >= = &&`. Rounding idiom: `round(x * 10) / 10` (1 dp), `* 100) / 100` (2 dp). Output is a double.
- Checked and working: `toInt(substr($c$, 0, 4))` in String Manipulation with `return_type="java.lang.Integer"`;
  Row Filter operator `WILDCARD` on strings (`"*-Q2"`); Row Filter with two predicates and `match="AND"`; GroupBy methods `Sum`, `Count`,
  `Missing value count`; Constant Value Column with `replace=True`; Concatenate of two inputs; Rule Engine `MATCHES` regex.
- Rule Engine with no catch-all rule gives a **missing** value, which the CSV Writer writes as a blank (what the contract wants for `series_note`).
  Flags: write the text `"TRUE"`/`"FALSE"` from the rule, never a boolean.
- CSV Writer quotes strings and writes missing as blank; `compare.py` reads both forms.
- Joiner on `year`: all three year columns are Integer (Excel, ARDD CSV, `toInt` of the ABS period); keep it that way, otherwise a strict join finds no match.
  Joiner column lists decide the output columns; the right key column is merged away.
- GroupBy returns rows sorted by the group columns; the Joiner here keeps that order. Pivot columns are named by the pivot value only (`2011`).
- Do not add Python/Java Snippet nodes. Only standard nodes; add model builders to `knimelib.py` if a node needs one (templates live in `templates/`).
- `knime/BeyondTheRoadToll/data/` holds copies of the 5 input files plus the outputs; it is rebuilt by `build_workflow.py`.
  The folder is generated: edit the Python, not the XML.
