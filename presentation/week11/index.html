Claim 1

The road toll is falling. The injury toll isn’t.

39,505 hospitalised in 2021 — about 108 people a day.

35 hospitalised for every road death (up from 27).

Road deaths −11.5%, hospitalisations +16%. Per person, the hospitalisation rate barely moved.

Indexed to a common base — the gap between the lines is the story.

Cycling injuries more than doubled among over-65s.

4

Visualisation design

One chart per claim — chosen, not defaulted to.

Unit chart

Makes an abstract ratio human: one dark dot = one death among ~35 hospitalised.

Indexed line

Compares three series of different size on 2011 = 100, so the gap is legible.

Heatmap + panels

Two categorical dimensions; aligned severity panels share one age axis.

  • Rejected: pie (not part-to-whole), dual axis (misleading), radar, small multiples (too tall on mobile).
  • 3-year averages over single years — so “more than doubled” is defensible.
  • Log-ratio colour — halving and doubling read as equal-and-opposite.
5

Interaction design

Five goals: orient, compare, personalise, drill down, inspect.

  • Find yourself → select road user + age, read a plain-language sentence.
  • Drill down → click a cell for that group’s yearly trend.
  • Compare → Counts / Per person toggles on both chapters.
  • Inspect → hover/focus tooltips; a data table behind every chart.
  • Parity → keyboard (arrows, Enter/Space), touch, and reduced motion.

State model

default → hovered → selected → mode (counts/per person) → low-count (hatched) → resized. Selection survives a mode change; nothing important is hover-only.

6

Website design

A newspaper page, not a dashboard.

  • No nav — the story is the navigation; one anchor to methods.
  • 760px prose, 980px figures; serif body, sans labels.
  • Orange = rise, blue = fall on a warm paper background.
  • Mobile-first at 375px; tables scroll, not the page.
  • Semantic HTML, keyboard, reduced motion, colour-blind-safe.

Coding plan

Six CSVs → four chart modules, one set of shared constants.

Data → charts

6 clean CSVs feed a unit chart, indexed lines, heatmap + trend, and severity panels. Prose numbers are computed from the same data.

Shared constants

CSS colour tokens, breakpoints (600/560/479), 2011 = 100 index, log-ratio scale (−60%…+150%).

QA + deploy

node --check; headless render at 375/768/1280; keyboard + reduced-motion walkthrough; copy website/ to Mercury.

Remaining (next, not done): team/GitHub/licence placeholders, downloadable CSV, usability testing, Mercury deployment. Phase 2 (counterparty severity, COVID, equity) is a documented backlog.
