# Beyond the Road Toll: slide deck

16:9 Beamer deck (16 slides) for the COS30045 project pitch.

## Build
```
# 1. figures (vector PDFs from data/clean/*.csv; needs pandas + matplotlib)
python presentation/make_figures.py

# 2. deck (needs TinyTeX/TeX Live with beamer, sourcesans, sourceserif, extsizes, ly1)
cd presentation
latexmk -pdf beyond_the_road_toll.tex
latexmk -c        # remove aux files, keeps the PDF
```
Missing packages: `tlmgr install sourcesans sourceserif extsizes ly1`.

`figures/website_heatmap.png` is a cropped headless-Chrome screenshot of the website heatmap section (static file, not regenerated by the script).
